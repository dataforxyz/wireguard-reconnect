# Code of conduct

Be respectful, technically honest, and constructive.

- Critique code and claims, not people.
- Do not publish another person's credentials, identity, network details, or
  vulnerability report without permission.
- Avoid harassment, discrimination, threats, and intentionally disruptive
  behavior.
- Give reporters time to address security issues privately before disclosure.
- Clearly label untested assumptions and avoid overstating security guarantees.

Maintainers may edit, hide, or remove contributions that violate these rules and
may restrict participation when necessary to protect contributors and users.
Serious conduct concerns should be reported privately through the repository's
GitHub contact mechanisms rather than debated in a public issue.
